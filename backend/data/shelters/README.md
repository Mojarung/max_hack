# Реестры укрытий по регионам

Папка для CSV-файлов с укрытиями, которые публикуют регионы. Загруженные точки получают
`official = true`, пометку источника «Реестр ...» и показываются первыми: по расстоянию, но
с чипом «Реестр» в приложении и подписью «из реестра» в чате.

## Откуда брать списки

Единого федерального реестра укрытий в открытом доступе нет. Адреса публикуют администрации
регионов и городов и региональные главные управления МЧС: на своих сайтах, в разделах
«Гражданская оборона» и «Безопасность», в виде таблиц, PDF и интерактивных карт. Формат у
каждого региона свой, поэтому список сначала приводят к CSV ниже руками или скриптом.

Если для региона списка нет, приложение само показывает заглублённые объекты из OpenStreetMap:
подземные паркинги, подземные переходы, входы в метро, бункеры. Это то, что МЧС называет
укрытием простейшего типа при беспилотной опасности. Такие точки помечены «OpenStreetMap»,
`official = false`, и обновляются не чаще раза в неделю на ячейку карты 0,02°.

## Формат файла

Кодировка UTF-8 (BOM от Excel допустим), разделитель запятая или точка с запятой.
Заголовок обязателен, порядок колонок любой.

| Колонка    | Обязательна | Что писать |
|------------|-------------|------------|
| `name`     | да          | название: «Укрытие в подвале школы № 12» |
| `address`  | да          | адрес с городом: «Орёл, ул. Ленина, 12» |
| `lat`      | нет         | широта, десятичная (54.3857); пусто = геокодируем по адресу |
| `lon`      | нет         | долгота, десятичная (48.6060); пусто вместе с `lat` |
| `capacity` | нет         | вместимость, человек |
| `kind`     | нет         | `shelter` (по умолчанию), `basement`, `parking`, `underpass`, `metro`, `bunker` |

Пример (адреса условные, только чтобы показать формат):

```csv
name,address,lat,lon,capacity,kind
Укрытие в подвале школы (пример),"Орёл, ул. Примерная, 12",52.96712,36.06380,400,basement
Подземный паркинг (пример),"Орёл, ул. Образцовая, 4",,,800,parking
```

Строки без координат геокодируются через Nominatim (OpenStreetMap) не чаще одного запроса
в секунду, как требуют правила сервиса. Если адрес не нашёлся, строка пропускается, а в логе
остаётся предупреждение `shelters.not_geocoded` с названием и адресом.

## Команда

```bash
cd backend
uv run domovoy import-shelters data/shelters/RU-ORL.csv --region RU-ORL --source "Реестр укрытий Орловской области"
```

- `--region` - код региона по ISO 3166-2 (`RU-ORL`, `RU-ULY`, `RU-MOW`).
- `--source` - название реестра, как его увидит житель. В базе хранится как `registry:<название>`.

Повторный запуск с тем же файлом обновляет координаты, вместимость и вид у существующих
записей (ключ: источник, название и адрес) и добавляет новые. Итог печатается в консоль:
сколько добавлено, обновлено, геокодировано и пропущено.

Файлы `*.csv` в этой папке можно хранить в репозитории: они маленькие и не содержат
персональных данных.
